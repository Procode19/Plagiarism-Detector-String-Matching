# 🔍 Plagiarism Detection Engine

An industry-oriented **Plagiarism Detection System** built using **Python, Streamlit, and Data Structures & Algorithms (DSA)** to identify exact and modified plagiarism through advanced string matching techniques.

## 🚀 Features

* ✅ Exact plagiarism detection
* ✅ Modified plagiarism detection
* ✅ KMP (Knuth–Morris–Pratt) Algorithm
* ✅ Rabin–Karp Algorithm
* ✅ Naive String Matching
* ✅ Similarity Score Calculation
* ✅ Automatic Report Generation (`report.txt`)
* ✅ Interactive Streamlit Frontend
* ✅ Professional UI Dashboard

---

---

## 📌 Algorithms Implemented

### 1. Naive String Matching

Detects exact sentence matches between original and submitted documents.

### 2. KMP Algorithm

Efficient pattern-matching algorithm used to detect partial plagiarism with optimized time complexity.

### 3. Rabin–Karp Algorithm

Hashing-based string matching technique for plagiarism verification and text similarity detection.

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPO_LINK
```

Move into the project folder:

```bash
cd Plagiarism-Detector-String-Matching
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Streamlit App:

```bash
streamlit run app.py
```
